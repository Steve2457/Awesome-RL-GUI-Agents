# Contributing to Awesome RL for GUI Agents

We welcome contributions to this list! If you have a paper, dataset, or tool that relates to Reinforcement Learning in GUI Agents, please feel free to submit a Pull Request.

## How to Contribute

1.  **Check for duplicates**: Ensure the resource isn't already listed.
2.  **Follow the format**: Use the existing table format (Paper Title, Year, and link).
3.  **Provide a link**: Ideally, provide a link to the arXiv page or the official project page.
4.  **Category**: Add your resource to the most appropriate section. If a new section is needed, please suggest it in your PR.

## Criteria for Inclusion

-   **Relevance**: Must be clearly related to Reinforcement Learning and GUI Agents (Mobile, Web, or Desktop).
-   **Quality**: Peer-reviewed conference/journal papers or high-impact preprints.
-   **Utility**: Datasets and environments that are publicly accessible or useful for the community.

Thank you for helping keep this list up to date!
